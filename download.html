Downloads

Download TIMBR Hub

The office side of TIMBR, for Mac and Windows. It signs in with your own Microsoft 365 account and reads and writes the same records as the phone app, in your own tenant. Nothing is installed on a server anywhere.

Mac

TIMBR Hub for Mac

Apple silicon, macOS 11 or later. Signed and notarised, so it opens without any warning.

Download for Mac

  • Unzip it and drag TIMBR Hub to Applications
  • Open it and sign in with your work Microsoft 365 account

Windows

TIMBR Hub for Windows

Windows 10 or 11, 64-bit. Nothing else to install: everything it needs is in the folder.

Download for Windows

  • Extract the whole zip somewhere you keep programs, open the TIMBR Hub folder and run SGArboricultureHub.exe
  • During the beta Windows shows a SmartScreen notice for a new publisher: choose More info, then Run anyway

Before you open it

The Hub works inside a SharePoint site your organisation creates and grants to it: one site, nothing else in your tenant. Setting that up takes an administrator about thirty minutes, once. Getting started walks through it step by step, including exactly which permissions the consent screen should show.

Updates

The Hub checks for a newer build when it opens and says so beside its build number; Settings › Check for updates does the same on demand, and Update now downloads it, swaps it in and reopens. Every release is listed, with what changed, on the releases page. The build number you see in the Hub is the release's name, so the two are easy to match up.

The rest of the suite

TIMBR Field, the phone app, is in open beta on iPhone and iPad: install it through TestFlight (Apple's TestFlight app installs first if you don't have it). On Android it is installed through Google Play testing during the beta; apply for the beta and the invitation comes with it. The QGIS plugin is installed from the Hub itself (Deployment › Sync plugin), which puts the right build into your QGIS profile.

Set it up once, properly

A dedicated site, one consent, one grant. Then each person installs and signs in with their own account.
